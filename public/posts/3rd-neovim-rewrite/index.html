Rewriting my Neovim configs for the 3rd time.

21 April 2026·278 words·2 mins
Neovim Vim Dotfiles Lua Lazyvim Text Editor

Neovim es mi editor de texto favorito de todos los tiempos. Lo utilizo desde hace algunos años ya, específicamente, desde el 2021 cuando quería empezar a programar. Mi primera opción fue Visual Studio Code, pero mi poderosísima laptop con sus 2GB de ram iba super lagueada con ese programa, por lo que necesitaba algo ligero que corriera sin mayor problema en esa maquina.

Mi primera opción fue usar Nano, que para editar algún que otro archivo de configuración estaba bien, el problema residía en que se quedaba corto para otras funciones que necesitaba.

Para ese tiempo ya había escuchado acerca de VIM y cómo todos los que lo utilizaban estaban enamorados de él, y al ser un programa de terminal sin interfaz gráfica era perfecto para mi uso, pues podía utilizarlo para editar mis archivos de configuración sin la necesidad de depender de la interfaz gráfica después de instalar Arch Linux por ejemplo, y actualmente para gestionar mi servidor. Pero también permitía ser un editor completo que poco o nada tenía que envidiar a un VS Code (solo que sí extrañe el doki-theme un poco, pero eso ya es cosa mía XD.)

Después de un poco de mi historia innecesaria de porqué utilizo Neovim pasamos a mi primera configuración.

Inicié con el gestor de plugins vim-plug ya que era el que estaba disponible en esa época (desconozco si ya existían otros) y le puse algún que otro plugin para añadir funcionalidad. Pero entonces me topé con este curso del usuario hola mundo y lo completé (algo gracioso es que ahora Udemy no me lo cuenta como completado, es más, como si nunca lo hubiera empezado xd.)
